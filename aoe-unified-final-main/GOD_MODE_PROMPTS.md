## Five-Box Prompt Framework

The most effective prompt structure:

1. **Role**: Who should the AI pretend to be?
2. **Task**: What is the actual output you want? (Start with a verb)
3. **Context**: What background information should the AI consider?
4. **Constraints**: Define the rules or limits (format, tone, word count)
5. **Format**: How should the response be structured?

Example:
```
Role: Senior Product Manager at a Fortune 500 tech company
Task: Design a user onboarding flow
Context: SaaS product for small businesses, 70% churn in first month
Constraints: 5-step maximum, mobile-first, under 100 words
Format: Numbered steps with brief descriptions
```

## Prompt Chaining for Complex Tasks

Break complex tasks into sequential prompts:

1. **Analysis Phase**: Gather information and identify components
2. **Design Phase**: Create specifications and requirements
3. **Implementation Phase**: Build the solution step-by-step
4. **Optimization Phase**: Refine and improve
5. **Validation Phase**: Test and verify

## Meta-Prompting

```
"I need help crafting the perfect prompt for [task].
What information do you need from me to create the optimal prompt?
Please ask me questions to gather the necessary context."
```
