BRIDGE AI OS

AUTONOMOUS · ON-CHAIN · SOVEREIGN FINANCIAL INFRASTRUCTURE

Bridge AI OS is a full-stack autonomous AI operating system deployed on Vercel (serverless) + VPS (brain.js), backed by the Linea L2 zkEVM blockchain. It combines a real-time agent swarm, an SVG skill engine, an on-chain treasury, and a modular vertical SaaS stack into a single unified platform.

AGENT NETWORK
8 L1/L2/L3 agents · autonomous task dispatch · swarm consensus
ON-CHAIN ECONOMY
BRDG token (Linea mainnet) · 4-bucket treasury · UBI distribution
SKILL ENGINE
SVG-native skill visualizer · 8+ skill types · LLM-powered learning
Live production: go.ai-os.co.za — Vercel frontend + API + live-map + dashboard

Treasury Buckets — Config E

Every inbound revenue event is split automatically into 4 buckets before BRDG is minted:

BucketSharePurpose
ops45%Operations — infrastructure, payroll, hosting
growth15%Marketing, affiliate payouts, lead gen
reserve15%Emergency fund, liquidity reserve
founder25%Founder distribution (TVM-gated)

Universal Basic Income (UBI)

1% of every treasury event flows to the UBI pool. Eligible wallets (verified citizens / agents) can claim a proportional share via POST /ubi/claim. Claims are logged on Linea via the TreasuryVault contract.

Deployment

Vercel (Production)

# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod

# Build command (auto-runs):
node build-static.js   # generates public/ + SVG assets

VPS (brain.js)

# SSH to VPS
ssh root@102.208.231.53

# Restart via PM2
pm2 restart brain
pm2 restart bridge-gateway

# Health check
curl https://go.ai-os.co.za/health
