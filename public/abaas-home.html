Integrate AI agents into your application with a single REST call.

# Execute an agent via the ABaaS API curl -X POST https://api.ai-os.co.za/agents/execute-paid \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "agent_id": "agent-biz-sales", "prompt": "Find 10 leads for AI startups in Cape Town" }' # Response { "ok": true, "output": "Found 10 AI startups in Cape Town...", "tokens_used": 842, "cost": "R0.50" }
