**Last updated:** 2026-04-17

The single canonical index for this repository. It does not duplicate source prose — it points at source files with `path:line` citations and flags drift.

## How to use

- Start at `docs/book/00-overview.md` for the one-page map of what this system is and how its processes fit together.
- If you are troubleshooting a specific symptom (401, 502, slow RLS query, unbalanced ledger, PayFast signature mismatch), consult `docs/book/TVM.json → problem_patterns` to pick the right chapter.
- If a claim in a chapter looks stale, cross-check the cited source file — the source is authoritative, not this index.
- Conflicts and known gaps are in `docs/book/14-gaps-and-conflicts.md`; resolve those before quoting the affected chapter.
