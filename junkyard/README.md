# junkyard/

Forensic archive of superseded documentation and scripts. **Not canonical.**

Files here are older copies of documents that also exist (in updated form) at the repo root or in `docs/`. They are retained for audit trails and historical reference. When reading documentation, always prefer the root-level or `docs/` version — use this directory only when you need to see what a document looked like at an earlier point in time.

For the canonical index of documentation, start at [`docs/BOOK_OF_KNOWLEDGE.md`](../docs/BOOK_OF_KNOWLEDGE.md). Chapter 13 (`docs/book/13-index-of-sources.md`) classifies every `.md` in the repo as canonical / historical / duplicate / stub; all files here are classified as **duplicate** or **historical**.

If you are about to delete this directory: first confirm there are no references in live scripts (grep `junkyard/` across the tree); none are expected, but verify before removing.
